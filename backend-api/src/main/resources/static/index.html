📖 사용 가이드

  1. JWT 토큰 발급: Swagger에서 로그인 API를 호출하여 토큰을 복사하세요.
  2. Client Key 입력: 토스페이먼츠 개발자센터에서 발급받은 테스트 키를 입력하세요.
  3. 장바구니 담기: 원하는 도서를 장바구니에 추가합니다.
  4. 결제하기: 일반 결제 또는 정기 구독을 선택하여 결제를 진행합니다.
